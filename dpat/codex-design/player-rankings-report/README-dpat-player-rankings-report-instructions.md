This folder contains the Codex design packet for the DPAT Player Rankings report.

- `../../report-designs/player-rankings/`

## Report Format

- Letter portrait PDF, `8.5in x 11in`.
- One-page leaderboard report unless the brief changes.
- Built for portfolio/report presentation, not website publishing.

## Design Rules

- Follow the current DPAT report family.
- Use black/near-black background with thin DPAT gold border.
- Main title uses `Impact, "Arial Black", Arial, sans-serif`, `30pt`, line-height `0.9`, and letter spacing `0`.
- Use bold Arial/Helvetica for small table text.
- Use DPAT gold `#F6C400` and border gold `#D6A000`.
- Use Season Total positive green `#00B818`.
- Use negative red `#D40000`.
- Use white card bodies with light gray row striping.
- Keep table values black for readability.
- Top-five card headers match Season Total: `Impact, "Arial Black", Arial, sans-serif`, `10.2pt`, `0.25in` tall.
- Table subheaders match Season Total leaderboard cards: `6pt`, bold, centered, and vertically middle aligned.

## Player Rankings Layout

Keep the current section order:

1. Header: 94 Feet Defender Badge, title, subtitle, gold podium/crown rankings icon.
2. Performance Ratings.
3. Possessions Per Game.
4. Positive Defensive Impact.
5. Negative Plays / Accountability.
6. Season Total-style footer strip.

Section-header rules:

- Performance Ratings and Possessions Per Game use black section bars with gold icon/title text.
- Positive Defensive Impact uses a black section bar with green `#00B818` thumbs-up icon and title text.
- Negative Plays / Accountability uses a black section bar with red `#D40000` thumbs-down icon and title text.
- Positive card headers stay solid green `#00B818` with white Impact/Arial Black type.
- Negative card headers stay solid red `#D40000` with white Impact/Arial Black type.
- Possessions Per Game uses the red two-arrow possession icon.
- Footer uses the Season Total-style black strip with gold top rule, basketball mark, breadcrumb text, and page number.
- Do not use the boxed DPAT Value Statement footer on current DPAT reports.

Each leaderboard section uses four cards:

- Overall
- Man
- 50
- 21

Do not use archived Player Rankings files as current direction.
