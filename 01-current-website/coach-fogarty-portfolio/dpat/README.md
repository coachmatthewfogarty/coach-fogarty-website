The current Season Total direction is:

- Black/near-black canvas with thin DPAT gold border.
- Main title in `Impact, "Arial Black", Arial, sans-serif`.
- Bold Arial/Helvetica body and table text for PDF readability.
- DPAT gold `#F6C400`.
- Border gold `#D6A000`.
- Season Total positive header green `#00B818`.
- Elite/positive KPI icon green `#00E51D`.
- Negative red `#D40000`.
- Defensive scale runs left-to-right from Liability to Elite.
- KPI icons: calendar, thumbs-up, thumbs-down, gold balance scales, trend chart, and gold header shield.

The current Player Rankings direction is:

- Letter portrait, one-page leaderboard report.
- Header title matches the Season Total title treatment: `Impact, "Arial Black", Arial, sans-serif`, `30pt`, letter spacing `0`.
- Header uses the 94 Feet Defender Badge on the left and the gold podium/crown ranking icon on the right.
- Top-five card headers match Season Total top-five headers: `Impact, "Arial Black", Arial, sans-serif`, `10.2pt`, `0.25in` tall.
- Table subheaders match Season Total leaderboard headers: `6pt`, bold, centered, and vertically aligned.
- Positive Defensive Impact section bar uses a black background with green `#00B818` icon and title text.
- Negative Plays / Accountability section bar uses a black background with red `#D40000` icon and title text.
- Positive and negative card headers remain solid green/red with white Impact/Arial Black type.
- Possessions Per Game uses the red two-arrow possession icon.
- Footer uses the Season Total-style black strip with gold top rule, basketball mark, breadcrumb text, and page number.

The current Game Report direction is:

- Letter landscape, 5 full pages.
- Page order: Overall, Man, 50, 32, 21.
- Use Cuesta, Game 14, December 19, 2025 as the starting build.
- Keep the old game-report PDF/screenshots as structure references only.
- Use the updated DPAT brand system, not the older plain spreadsheet visual direction.
- Footer uses the Season Total-style black strip; do not use boxed value-statement footers on current DPAT reports.

## Folder Roles

- `codex-design/`: current visual references, briefs, screenshots, and non-editable design packet materials.
- `source-data/`: source workbooks and CSV references.
- `report-designs/`: editable HTML/CSS/JS build files and current brand/design guides.
- `final-reports/`: final PDFs and final proof exports.
- Historical DPAT archives now live outside the active website folder at `../../../04-archive/dpat-archive-2026-05-08/`.

## Avoid

- Do not use archived files as current direction.
- Do not use older shield-icon language for Season Total KPI cards.
- Do not use `#168A2F` for Season Total dashboard positive headers; that belongs to the Action Leaderboard positive page accent.
- Do not use the older Player Rankings green/red full-width section-banner direction; the approved section bars are black with colored icon/title text.
- Do not overwrite source workbooks or source CSVs.
- Do not publish these report files to the website.
