## Design Rules

- Use the updated DPAT report design system from `../README-dpat-report-design-system.md`.
- Match the Season Total title, defensive scale, colors, and footer system unless the Game Report needs a clear functional adjustment.
- Footer should use the Season Total-style black strip with gold top rule, basketball mark, breadcrumb text, and page number.
- Do not use boxed value-statement footers on current DPAT reports.
- Keep the old report screenshots as layout/data references only; the new template should use the updated DPAT visual language.
