# Gallery Page Interaction Spec

Status: active as of 2026-05-14.

## Overlay / Lightbox

Markup lives in `media.html` as `#mediaOverlay.media-overlay`. Runtime behavior lives in `app.js`.

Core selectors:

- Trigger cards/buttons: `[data-open-media-gallery]`, `.media-library-card`, `.media-category-card`.
- Overlay: `.media-overlay#mediaOverlay`.
- Panel: `.media-overlay-panel`.
- Close: `#mediaOverlayClose.media-overlay-close`.
- Prev/next: `#mediaOverlayPrev.media-overlay-prev`, `#mediaOverlayNext.media-overlay-next`.
- Viewer: `#mediaOverlayViewer.media-overlay-viewer`.
- Caption: `#mediaOverlayCaption.media-overlay-caption`.
- Counter: `#mediaOverlayCounter.media-overlay-counter`.
- Thumbnail shell: `#mediaOverlayStripShell.media-overlay-strip-shell`.
- Thumbnail buttons: `.media-thumb`.
- Thumb nav: `#mediaOverlayThumbPrev`, `#mediaOverlayThumbNext`.

Desktop overlay rules:

- Base overlay: fixed inset 0, z-index 100, centered flex when open, padding 24px, background `rgba(15, 12, 10, 0.82)`.
- Base panel: width `min(100%, 980px)`, max-height `min(calc(100vh - 48px), 820px)`, padding 26px, radius 28px, border `1px solid rgba(255, 250, 243, 0.22)`, background `rgba(31, 27, 22, 0.96)`, shadow `0 28px 90px rgba(0,0,0,0.44)`.
- Gallery overlay panel: width `min(calc(100vw - 48px), 860px)`, height/max-height `min(calc(100vh - 32px), 760px)`, overflow hidden, padding `clamp(16px, 2.2vw, 26px)`.
- Content grid: eyebrow, title, counter, viewer, caption, strip. Gallery overlay viewer row is `minmax(0, 1fr)`; strip row is based on thumbnail height.
- Viewer: contains img/video absolute inset, 100% width/height, `object-fit: contain`, `object-position: center center`.
- Caption: color `rgba(255, 247, 235, 0.78)`, line 1.5; gallery caption max-height 3em with auto overflow.
- Thumbnail default: width `clamp(88px, 9.6vw, 120px)`, height `clamp(58px, 6.4vw, 80px)`, radius 12px, 2px translucent cream border. Active state border `var(--gold)` plus 2px gold glow.
- Close button: 42px square, top/right 16px, radius 999px, color #fff7eb.
- Main arrows: 48px x 58px, vertically centered, left/right 14px, font-size 2.4rem.
- Thumb arrows: 38px x 48px, radius 999px.

Mobile overlay <=720px:

- Overlay padding 8px.
- Panel max-width 460px, max-height `calc(100dvh - 16px)`, radius 22px.
- Overlay padding variable: `clamp(10px, 2.8vw, 14px)`.
- Thumb width `clamp(72px, 22vw, 92px)`; height `clamp(48px, 15vw, 62px)`.
- Thumb nav buttons are hidden on mobile; the strip scrolls horizontally.
- Main prev/next buttons move near the bottom above thumbnails, 40px square.
- Overlay headings reserve right padding for close button.

## Carousel / Preview Strip

- Preview carousel markup is generated by `previewCarouselMarkup(key, cards, renderCard)`.
- Desktop/tablet preview count: 3 cards.
- Mobile preview count <=720px: 1 card.
- Arrows exist when there are more cards than visible count.
- Arrow buttons: `.media-carousel-arrow`, 44px square desktop, 40px mobile bottom controls.
- Swipe support: `enableSwipeCarousel(track, moveCarousel)` is enabled when state has more than 3 cards.

## Keyboard And Focus

- `openMediaAlbum()` focuses the close button after opening.
- Escape closes the overlay.
- ArrowLeft/ArrowRight change items only when corresponding arrow is visible.
- Clicking backdrop closes the overlay.
- Clicking viewer advances to next item for non-video media when next exists.

## Header / Footer Interaction

- Header scroll reveal in `footer.js`: hides after downward scroll threshold 16px past page top unless nav is open; reveals on upward delta greater than 2px or near top.
- Mobile nav opens/closes through `.nav-open`, toggles hamburger aria-expanded and aria-label.
- Footer accordions activate at max-width 820px; button toggles `.is-open`, aria-expanded, and link list display.

## Stale/Archive Candidates

- `renderGallery()` remains active for Home Media and is not stale.
- `.media-album-section` CSS is not used by current Gallery Hub renderer but may be shared/legacy; do not remove without cross-page audit.
- Older `.subpage-hero` fallback and approved-left-lock selectors have been removed from reusable hero behavior. Gallery uses `.page-hero-system` across desktop, tablet, and mobile.
